| Scope | Attribution | Included source |
|---|---|---|
| UAV takeoff / landing and mission-sequence integration | Portfolio owner | Curated, parameterized public adapter |
| UGV waypoint driving | Team subsystem | Not included; event/command interface only |
| UAV waypoint flight | Team subsystem | Not included; event/command interface only |

Team consent to publish this curated repository is confirmed. Keep the existing
scope boundaries if additional source is proposed: obtain a separate review for
any new subsystem excerpt or vendor/runtime code, and do not infer sole
authorship from the destination GitHub account.
